Les Fonctions Polynômes

timer 15 min school Mathématiques

menu_book Résumé du cours

expand_more

Une fonction polynôme de degré 2 (ou trinôme) est une fonction $f$ définie sur $\mathbb{R}$ par :

$f(x) = ax^2 + bx + c$

Où $a, b, c$ sont des réels avec $a \neq 0$.

La forme canonique

Toute fonction polynôme de degré 2 peut s'écrire sous la forme :

$f(x) = a(x - \alpha)^2 + \beta$

Avec $\alpha = \frac{-b}{2a}$ et $\beta = f(\alpha)$.

lightbulb Exemple Résolu

Déterminer la forme canonique de : $f(x) = 2x^2 - 12x + 10$

  1. Identifier $a, b, c$ : $a = 2$, $b = -12$, $c = 10$.
  2. Calculer $\alpha$ : $\alpha = \frac{-(-12)}{2(2)} = \frac{12}{4} = 3$.
  3. Calculer $\beta$ : $\beta = f(3) = 2(3)^2 - 12(3) + 10 = 18 - 36 + 10 = -8$.
  4. Conclure : $f(x) = 2(x - 3)^2 - 8$.

À ton tour ! Quelle est la valeur de $\alpha$ pour la fonction $g(x) = -3x^2 + 6x - 1$ ?
