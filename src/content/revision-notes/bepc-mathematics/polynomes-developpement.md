# Comprendre simplement

Développer un produit de deux facteurs, c'est multiplier chaque terme du premier facteur par chaque terme du second, puis additionner les résultats.

Quand deux produits sont additionnés, on développe chaque produit séparément avant de regrouper les termes semblables.

# Exemple concret

**Situation :** Développer `(x + 2)(x + 5)`.

**Étape 1 :** Multiplier `x` par chaque terme du second facteur : `x×x + x×5 = x² + 5x`.

**Étape 2 :** Multiplier `2` par chaque terme du second facteur : `2×x + 2×5 = 2x + 10`.

**Étape 3 :** Additionner les quatre termes : `x² + 5x + 2x + 10`.

**Étape 4 :** Réduire les termes semblables : `x² + 7x + 10`.

**Conclusion :** `(x + 2)(x + 5) = x² + 7x + 10`.

# Les erreurs fréquentes

## Oublier un des quatre produits

- Erreur : ne calculer que trois des quatre produits, souvent le terme croisé.
- Pourquoi : on multiplie terme à terme trop vite sans méthode.
- Comment éviter : nommer les quatre produits avant de les additionner.

## Erreur de signe

- Erreur : traiter `-1×3` comme `+3` dans un produit comme `(2x - 1)(x + 3)`.
- Pourquoi : le signe du terme négatif est oublié pendant la multiplication.
- Comment éviter : multiplier les signes en même temps que les nombres.

## Additionner avant de développer

- Erreur : additionner les facteurs de deux produits avant de développer, par exemple traiter `(x+2)(x+3) + (x-1)(x+4)` comme un seul produit.
- Pourquoi : on confond somme de produits et produit de sommes.
- Comment éviter : développer chaque produit séparément, puis additionner les résultats.

# À retenir

- Multiplier chaque terme du premier facteur par chaque terme du second.
- Garder les signes pendant toute la multiplication.
- Quand deux produits sont additionnés, développer chacun séparément avant de réduire.

# Mini exercice

## Exercice 1

**Énoncé :** Développer `(2x - 1)(x + 3)`.

**Réponse :** `2x² + 5x - 3`.

**Correction :** `(2x - 1)(x + 3) = 2x² + 6x - x - 3 = 2x² + 5x - 3`.

## Exercice 2

**Énoncé :** Développer et réduire `(x + 2)(x + 3) + (x - 1)(x + 4)`.

**Réponse :** `2x² + 8x + 2`.

**Correction :** `(x² + 5x + 6) + (x² + 3x - 4) = 2x² + 8x + 2`.
