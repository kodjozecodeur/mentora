# Comprendre simplement

Trois produits reviennent très souvent et peuvent être développés directement, sans refaire les quatre multiplications à chaque fois :

`(a + b)² = a² + 2ab + b²`, `(a - b)² = a² - 2ab + b²`, et `(a + b)(a - b) = a² - b²`.

Reconnaître ces formes fait gagner du temps et évite des erreurs de calcul.

# Exemple concret

**Situation :** Développer `(3x + 4)(3x - 4)`.

**Étape 1 :** Reconnaître la forme `(a + b)(a - b)` avec `a = 3x` et `b = 4`.

**Étape 2 :** Appliquer la formule `a² - b²` : `(3x)² - 4²`.

**Étape 3 :** Calculer chaque carré : `9x² - 16`.

**Conclusion :** `(3x + 4)(3x - 4) = 9x² - 16`.

# Les erreurs fréquentes

## Oublier le double produit

- Erreur : développer `(4x + 1)²` en `16x² + 1`, en oubliant le terme du milieu.
- Pourquoi : on ne pense qu'aux deux carrés et on oublie `2ab`.
- Comment éviter : toujours écrire les trois termes `a² + 2ab + b²` avant de calculer.

## Oublier d'élever le premier terme au carré

- Erreur : écrire `(5x + 3)(5x - 3) = 5x² - 9` au lieu de `25x² - 9`.
- Pourquoi : on oublie d'élever `5x` au carré, pas seulement le 5.
- Comment éviter : mettre le terme entier entre parenthèses avant de l'élever au carré : `(5x)²`.

## Développer terme à terme sans reconnaître l'identité

- Erreur : garder un terme en x dans `(3x + 4)(3x - 4)`, par exemple `9x² - 24x - 16`.
- Pourquoi : on ne reconnaît pas la forme `(a + b)(a - b)`, où les deux termes croisés s'annulent.
- Comment éviter : vérifier si les deux facteurs ont les mêmes termes avec un signe opposé.

# À retenir

- `(a + b)² = a² + 2ab + b²`
- `(a - b)² = a² - 2ab + b²`
- `(a + b)(a - b) = a² - b²`

# Mini exercice

## Exercice 1

**Énoncé :** Développer `(5x + 3)(5x - 3)`.

**Réponse :** `25x² - 9`.

**Correction :** `(5x)² - 3² = 25x² - 9`.

## Exercice 2

**Énoncé :** Compléter `(4x + 1)² = ...`.

**Réponse :** `16x² + 8x + 1`.

**Correction :** `(4x)² + 2×4x×1 + 1² = 16x² + 8x + 1`.
