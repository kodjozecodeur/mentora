# Comprendre simplement

Le théorème de Thalès s'utilise quand deux droites sont coupées par des droites parallèles.

Les longueurs correspondantes sont proportionnelles. Il faut d'abord vérifier le parallélisme, puis écrire les rapports dans le même ordre.

# Exemple concret

**Situation :** Dans le triangle ABC, D est sur [AB], E est sur [AC] et (DE) est parallèle à (BC). On connaît `AD = 2 cm`, `AB = 5 cm` et `AC = 7,5 cm`. Calculer AE.

**Étape 1 :** Écrire les rapports de longueurs correspondantes : `AD / AB = AE / AC`.

**Étape 2 :** Remplacer les valeurs : `2 / 5 = AE / 7,5`.

**Étape 3 :** Isoler AE : `AE = 7,5 × 2 / 5 = 3 cm`.

**Conclusion :** La longueur cherchée est `AE = 3 cm`.

# Les erreurs fréquentes

## Oublier le parallélisme

- Erreur : appliquer Thalès sans voir deux droites parallèles.
- Pourquoi : une figure qui ressemble à une configuration de Thalès peut être trompeuse.
- Comment éviter : repérer et citer le parallélisme avant d'écrire les rapports.

## Mélanger les correspondances

- Erreur : associer AD avec AC et AE avec AB.
- Pourquoi : les segments sont écrits dans un ordre différent dans les deux rapports.
- Comment éviter : garder le même sens de lecture dans chaque rapport.

## Oublier l'unité

- Erreur : donner seulement le nombre 3.
- Pourquoi : le calcul est terminé mais la grandeur n'est pas nommée.
- Comment éviter : écrire l'unité à la dernière ligne.

# À retenir

- Vérifier les droites parallèles.
- Associer les côtés correspondants.
- Écrire les rapports dans le même ordre.

# Mini exercice

## Exercice 1

**Énoncé :** Dans une configuration de Thalès, `AD = 3 cm`, `AB = 6 cm` et `AC = 10 cm`. Calculer AE.

**Réponse :** `AE = 5 cm`.

**Correction :** `AD / AB = AE / AC`, donc `AE = 10 × 3 / 6 = 5 cm`.

## Exercice 2

**Énoncé :** On sait que `(DE) // (BC)`, `AD = 2 cm`, `AB = 5 cm` et `DE = 4 cm`. Si `BC` est le côté correspondant, calculer BC.

**Réponse :** `BC = 10 cm`.

**Correction :** `AD / AB = DE / BC`, donc `2 / 5 = 4 / BC`, d'où `BC = 4 × 5 / 2 = 10 cm`.
