# Comprendre simplement

Une équation est une égalité dans laquelle il y a une inconnue, souvent notée x.

Résoudre une équation, c'est trouver la valeur de x qui rend l'égalité vraie. Une égalité fonctionne comme une balance : toute opération faite à gauche doit aussi être faite à droite.

À la fin, on vérifie la réponse en remplaçant x dans l'équation de départ.

# Exemple concret

**Situation :** Résoudre `2x + 5 = 11`.

**Étape 1 :** Soustraire 5 aux deux membres : `2x + 5 - 5 = 11 - 5`, donc `2x = 6`.

**Étape 2 :** Diviser les deux membres par 2 : `2x / 2 = 6 / 2`, donc `x = 3`.

**Étape 3 :** Vérifier : `2 × 3 + 5 = 6 + 5 = 11`.

**Conclusion :** La solution de l'équation est `x = 3`.

# Les erreurs fréquentes

## Changer un seul membre

- Erreur : soustraire 5 à gauche mais pas à droite.
- Pourquoi : l'égalité est traitée comme une expression à simplifier d'un seul côté.
- Comment éviter : écrire chaque opération sur les deux membres.

## Se tromper de signe

- Erreur : transformer `x - 7 = 2` en `x = 2 - 7`.
- Pourquoi : le terme -7 est déplacé sans réfléchir à l'opération inverse.
- Comment éviter : ajouter 7 aux deux membres pour annuler -7.

## Oublier de diviser

- Erreur : conclure `x = 6` après avoir obtenu `2x = 6`.
- Pourquoi : le coefficient 2 devant x n'est pas supprimé.
- Comment éviter : isoler x avec l'opération inverse, ici une division par 2.

# À retenir

- Faire la même opération aux deux membres.
- Utiliser l'opération inverse pour isoler x.
- Vérifier la solution dans l'équation de départ.

# Mini exercice

## Exercice 1

**Énoncé :** Résoudre `3x - 2 = 10`.

**Réponse :** `x = 4`.

**Correction :** Ajouter 2 donne `3x = 12`, puis diviser par 3 donne `x = 4`.

## Exercice 2

**Énoncé :** Résoudre `5x - 3 = 3x + 7`.

**Réponse :** `x = 5`.

**Correction :** Soustraire `3x` donne `2x - 3 = 7`. Ajouter 3 donne `2x = 10`, puis diviser par 2 donne `x = 5`.
