# Comprendre simplement

Une fonction linéaire associe à un nombre x un nombre `f(x) = ax`, où a est un nombre fixe appelé coefficient.

Pour calculer une image, on remplace x par la valeur donnée puis on multiplie par a. Pour trouver un antécédent, on cherche le nombre qui donne l'image demandée.

# Exemple concret

**Situation :** On considère `f(x) = 3x`. Calculer `f(4)`.

**Étape 1 :** Repérer le coefficient de la fonction : `a = 3`.

**Étape 2 :** Remplacer x par 4 : `f(4) = 3 × 4`.

**Étape 3 :** Effectuer le produit : `3 × 4 = 12`.

**Conclusion :** L'image de 4 par f est `f(4) = 12`.

# Les erreurs fréquentes

## Ajouter au lieu de multiplier

- Erreur : calculer `f(4) = 3 + 4`.
- Pourquoi : le coefficient est pris pour un nombre à additionner.
- Comment éviter : se rappeler que `f(x) = ax` signifie a multiplié par x.

## Oublier le signe du coefficient

- Erreur : calculer `f(3) = 2 × 3 = 6` pour `f(x) = -2x`.
- Pourquoi : le signe moins devant le coefficient est oublié.
- Comment éviter : recopier le coefficient entier avant de remplacer x.

## Confondre image et antécédent

- Erreur : chercher x alors que la question demande l'image de x.
- Pourquoi : les deux mots semblent proches.
- Comment éviter : image = résultat obtenu ; antécédent = nombre de départ.

# À retenir

- Une fonction linéaire s'écrit `f(x) = ax`.
- Pour une image, remplacer x puis calculer.
- Le coefficient a garde son signe.

# Mini exercice

## Exercice 1

**Énoncé :** Pour `g(x) = 5x`, calculer `g(2)`.

**Réponse :** `g(2) = 10`.

**Correction :** Remplacer x par 2 : `g(2) = 5 × 2 = 10`.

## Exercice 2

**Énoncé :** Pour `h(x) = -2x`, calculer `h(3)`.

**Réponse :** `h(3) = -6`.

**Correction :** `h(3) = -2 × 3 = -6`. Le signe du coefficient reste négatif.
